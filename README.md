# haicon-tutorial
IPython notebooks to follow along for the HAICON 26 tutorial on 'Deep Learning with Bayesian Principles'. 

## Installation and Getting Started

Get `uv` and run

```shell
uv sync --locked
```

Then, try out the python notebooks to follow along :)
